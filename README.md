# 🍴 Food Lover

Food Lover is a modern web application built with **Next.js 16**, **TailwindCSS**, and **external APIs**.  
It’s more than just a food website — it’s a community for discovering, ordering, and reviewing delicious meals.

---

## 🌐 Live Demo

👉 [Visit Food Lover Live](https://your-deployment-link.vercel.app)

---

## 🚀 Features

- 📋 **Food Listings** – Browse a wide variety of dishes with names, prices, and detailed descriptions.
- 🔍 **Search & Filter** – Quickly find the food you’re craving using the search option.
- 🛒 **Add to Cart** – Seamlessly add items to your cart and prepare for checkout.
- ⭐ **Reviews & Ratings** – Read honest reviews from other food lovers before ordering.
- 🌍 **Community Hub** – Connect through shared flavors, culinary creativity, and inspiration.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/)
- **Styling:** [TailwindCSS](https://tailwindcss.com/)
- **Data:** External APIs for food details, pricing, and reviews
